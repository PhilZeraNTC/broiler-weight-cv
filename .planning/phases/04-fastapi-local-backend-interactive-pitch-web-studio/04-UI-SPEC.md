# Phase 04 — UI Design Contract

> Visual and interaction contract for **AvianScale CV** (`WEB-01` through `WEB-05`). Generated by `gsd-ui-researcher` in autonomous mode from `04-CONTEXT.md`, `REQUIREMENTS.md`, `STACK.md`, and published Phase 1–3 artifacts; verified by `gsd-ui-checker`.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (manual Tailwind CSS v4 `@theme` design tokens in `frontend/src/index.css`) |
| Preset | not applicable |
| Component library | none (custom semantic React 19 + TypeScript 7 primitives composed with `clsx` + `tailwind-merge`) |
| Icon library | `lucide-react` (`1.77.0`) |
| Chart library | `recharts` (`3.11.0`) paired with `react-is` (`19.3.1`) |
| Font | UI Sans: `"Inter", system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`; Technical Mono: `"JetBrains Mono", ui-monospace, SFMono-Regular, Menlo, monospace` |

**Design Token Architecture (Tailwind CSS v4 CSS-first `@theme`):**
- Single zero-config stylesheet (`frontend/src/index.css`) starting with `@import "tailwindcss";` followed by `@theme` custom properties locking the exact spacing, typography, and color palette declared below.
- Zero `tailwind.config.js`, zero PostCSS pipeline, zero shadcn initialization (`shadcn_initialized: false`), and zero external CSS frameworks.
- Language lock (`04-CONTEXT.md` `D-06`): All user-facing UI labels, headings, aria labels, empty/error states, tooltips, and disclaimers are written in Brazilian Portuguese (`pt-BR`); standard scientific terms (`MAE`, `RMSE`, `MAPE`, `BalMAPE`, `R²`, `CV%`, `CLAHE`, `EXIF`, `Watershed`, `LightGBM`, `OOF`, `EDT`) retain standard scientific notation.

## Spacing Scale

Declared values (strictly standard multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| `xs` | `4px` | Icon-to-label inline gaps, compact status badge inner padding, tight telemetry key-to-value separation |
| `sm` | `8px` | Compact control gaps, preset thumbnail strip gaps, filter pill gaps, form label-to-input spacing |
| `md` | `16px` | Default card padding, 2×2 X-Ray and Watershed stage grid gutters, form row gaps, mobile viewport horizontal padding |

| `3xl` | `64px` | Sticky top navigation bar height (`64px`) and page bottom breathing room on projector/desktop viewports (`≥ 1280px`) |

**Exceptions:** `44px` minimum interactive hit target (`min-h-[44px] min-w-[44px]`) applied strictly to icon-only action buttons (stage expand button, modal close/navigation buttons, flock row remove button, info popover button) and range slider thumbs — justified by WCAG 2.1/2.2 Target Size accessibility for rapid trackpad/touch operation during live pitch presentations. All layout padding, margin, and gap utilities remain strictly inside `{4px, 8px, 16px, 24px, 32px, 48px, 64px}`.
